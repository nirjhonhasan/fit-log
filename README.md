FitFlow - Modern Workout & Fitness

FitFlow is a modern, responsive web application built with Next.js and TypeScrip. 


Technologies Used

Framework: Next.js
Language: TypeScript
Styling: Tailwind CSS
State Management: React Context API
Notifications: React Toastify
Icons: React Icons


5 Key Features

1.Interactive Workout Library 

2.Today's Plan Management  

3.Saved Plans & Bookmarking

4.Advanced Sorting System

5.Modern & Responsive UI/UX
